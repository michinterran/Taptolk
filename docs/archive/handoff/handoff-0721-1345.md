## Contract change that needs a reviewer's attention

WCJ rule `J005` previously **required** the public onboarding page to contain an
`/admin/login` link. That directly contradicted this PRD's requirement of zero
administrator links on the public surface, so the rule was rewritten to enforce the
stricter reading:

- no administrator link anywhere on the public landing, onboarding, or public header;
- semantic heading groups on landing, onboarding, and the administrator portal;
- a single canonical administrator sign-in.

This is a deliberate gate change, not a relaxation. Reviewers should confirm the new
rule matches the intended product contract before this reaches Production.
