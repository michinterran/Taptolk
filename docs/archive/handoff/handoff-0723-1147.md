   `디자인 생성 → 디자인 승인 → 배치 요청 → 샘플 승인 → 최종 승인 → 제작`이라
   발주와 승인이 번갈아 일어난다. 단일 페이지 위자드로 만들 수 없다.
4. **Taptolk 직영**: `sites.management_company_id`가 notNull + 복합 FK라 "관리회사 없는

   플래그로 구분한다. **회사 이름으로 직영을 판정하지 않는다.**
5. **수량 정책은 도메인이 소유한다** — 배치 분할·슬라이더 상한 파생·권장 수량·초과 판정이
