# Archived session handoffs

세션 상태 기록이다. **설계 근거로 인용하지 않는다.**

여기 있는 문서들이 한때 설계 근거로 쓰였고, 그 결과 이미 컴펌된 시안과 다른 화면이 여러 번
만들어졌다. 예: `handoff-0723-1147.md`의 "QR 제작 3구역 분리"는 컴펌된 위자드 시안을 뒤집은
제안이었는데, 이후 세션이 시안 대신 그 문장을 근거로 화면을 만들었다.

화면이 어떻게 생겨야 하는지는 `DESIGN_SYSTEM.md`와 `docs/design-canon/`만이 정한다.
현재 상태는 `docs/handoff-*.md`의 최신 문서를 본다.

읽어도 되는 용도: 무엇이 언제 왜 결정됐는지의 이력, 적용된 마이그레이션 추적, 환경 함정.
