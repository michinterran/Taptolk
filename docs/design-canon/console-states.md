# 콘솔·플랫폼 상태 커버리지 (정본)

> 작성: Claude(디자인) 2026-07-25 · 정본. "화면이 각 상태에서 어떻게 보이는가"를 정한다.
> 상태 어휘는 `plan-design-completion-0724.md` §2(운영자 확정). 데이터는 `CONTRACTS.md`.
> **완료조건 5번**: 화면을 넘기기 전 해당 상태를 전부 그린다 — 나중에 몰아 붙이지 않는다.

## 0. 왜 이 문서

콘솔·플랫폼은 로그인 게이트라 실화면 대조가 스텝 D 이후로 밀려 있다. 그 사이 Codex가
화면을 배선할 때 **상태를 빠뜨리거나 화면마다 다르게 그리지 않도록**, 상태 패턴을 한 곳에
고정한다. 상태도 §2 단일 정의 규칙을 따른다 — 공통 블록을 재사용하고 화면은 델타만.

## 1. 상태 어휘 (6종, 전 화면 공통)

| 상태 | 규칙 | 쓰는 블록 |
|---|---|---|
| **빈(empty)** | 무엇이 생기면 채워지는지 말한다. 샘플로 채우지 않는다 | `.tt-empty-state` |
| **로딩(loading)** | 레이아웃이 튀지 않는다(스켈레톤) | §2-스켈레톤 (신규) |
| **오류(error)** | **복구 경로를 준다**(WCJ J004). 사유를 구분한다 | `.admin-notice--danger` + 인라인 |
| **권한 없음** | `0`이 아니라 `—`. 구역을 떼지 않고 **잠금·읽기 전용** | §2-잠금 (신규) |
| **한도 초과** | 남은 시간·횟수를 말한다 | `.admin-notice--warning` + 잔여 |
| **알 수 없음** | **"못 물어봤다"를 "없다"로 표시하지 않는다** | `—` + `확인 불가` |

## 2. 공통 상태 블록 (Codex 구현, 새 토큰 불필요)

### 빈 — `.tt-empty-state` (이미 있음)
- 아이콘/짧은 제목(h3) + 한 줄 설명 + (있으면)액션. **"○○을 등록하면 여기에 표시됩니다"**
  처럼 채워지는 조건을 말한다. 표 자리를 더미 행으로 채우지 않는다.

### 로딩 — 스켈레톤 (신규 패턴)
- 표·카드·지표 셀의 **자리를 유지**한 채 회색 블록으로 대체. 배경 `--tt-color-surface-muted`,
  라운드 `--tt-radius-sm`. 실제 행 높이(테이블 48px, 지표 셀)와 **같은 크기**라 로드 후
  레이아웃이 튀지 않는다.
- 은은한 shimmer 허용하되 `@media (prefers-reduced-motion:reduce)`에서 정지.
- 스피너 단독으로 큰 영역을 대체하지 않는다(위치가 튄다). 버튼 제출 중만 스피너.

### 오류 — `.admin-notice--danger` + 복구
- **복구 경로 필수**: `다시 시도` 액션 또는 원인 안내. WCJ J004.
- 사유 구분: 네트워크·권한·서버·검증을 다른 문구로(§CONTRACTS 사유 필드). 한 개의 일반
  문구로 뭉개지 않는다. 단 보안상 세부를 감춰야 하는 경우는 예외(자격 오류 등).
- **부분 오류**는 그 구역만 오류로, 화면 전체를 날리지 않는다.

### 권한 없음 — 잠금/읽기 전용 (신규 패턴)
- 구역을 **떼어내지 않는다.** 데이터는 보이되 액션(버튼·편집)을 `disabled` + 자물쇠 힌트.
- 값은 `—`(0 아님). 목록은 범위 밖 행을 아예 안 보내는 게 원칙(서버가 필터), 화면은
  받은 것만 그린다.
- 읽기 전용 감사자(Read Only Auditor)는 전 화면이 이 모드다 — 조회는 되고 조치는 잠김.

### 한도 초과 — `.admin-notice--warning` + 잔여
- **남은 시간/횟수를 말한다**(예: `30초 후 다시 시도`, `오늘 남은 export 2회`). 그냥
  "불가"로 막지 않는다. Rate limit·export·재시도에 적용.

### 알 수 없음 — `—` + `확인 불가`
- 서버가 값을 못 준 것과 값이 0인 것을 구분한다. 채널 상태·집계 실패는 `상태 확인 불가`,
  0건은 `0`. **"못 물어봤다"를 "없다/정상"으로 쓰지 않는다.**

## 3. 아키타입별 상태 (화면은 여기에 델타만 더한다)

### 목록 화면 (사이트·계정·테넌트·관리회사·매출·리포트)
| 상태 | 이 화면에서 |
|---|---|
| 빈 | 필터·검색 유지한 채 표 자리에 empty-state. "필터에 맞는 결과 없음" vs "아직 없음" 구분 |
| 로딩 | 필터바는 즉시, 표만 스켈레톤 행(페이지당 개수만큼). 페이지네이션 자리 유지 |
| 오류 | 표 영역만 오류+다시 시도. 필터바·헤더는 남긴다 |
| 권한 없음 | 조회는 되되 행의 `작업`(수정·초대·조치) 버튼 잠금. 내보내기도 권한 따라 |
| 한도 | 내보내기 한도 시 남은 횟수 |
| 알 수 없음 | 집계 셀(응답률 등)이 없으면 `—` |

### 대시보드 (대시보드·운영)
| 상태 | 이 화면에서 |
|---|---|
| 빈 | 지표 셀 `—`, 추이 그래프 빈 영역, 조치 항목 "지금 조치할 항목 없음" |
| 로딩 | 지표 스트립·그래프·조치 리스트 각각 스켈레톤(스트립은 한 카드 유지) |
| 오류 | 구역별 오류(지표 따로, 그래프 따로). 전체를 날리지 않음 |
| 알 수 없음 | 분모 0을 1로 바꿔 100% 만들지 않는다 → `—` |

### 상세 (관리회사 상세·내 정보·사이트 운영)
| 상태 | 이 화면에서 |
|---|---|
| 빈 | 하위 목록(소속 현장·멤버십·입고 이력) 각각 empty-state |
| 로딩 | 기본 정보 필드 스켈레톤, 탭/구역 자리 유지 |
| 권한 없음 | 편집 폼 읽기 전용, `수정` 잠금 |
| 오류 | 저장 실패 시 폼 위 인라인 오류 + 입력값 유지 |

### 위자드 (QR 제작 6단계)
| 상태 | 이 화면에서 |
|---|---|
| 로딩 | 단계 전환·샘플 렌더는 진행 표시. 스텝퍼 위치 유지 |
| 오류 | 그 단계에서 멈추고 사유+다시 시도. 앞 단계 입력 보존 |
| 한도 | 수량 `1..100` 초과 입력은 즉시 검증 오류(막지 말고 사유). 초과 정책은 착수 금지 |
| 권한 없음 | 슈퍼어드민 전용 — 비대상은 진입 불가(라우팅에서) |

## 4. 화면별 델타 (아키타입 + 특이사항)

| 화면 | 아키타입 | 특이 상태 |
|---|---|---|
| `/admin/dashboard` | 대시보드 | 조치 항목 빈 상태 문구 |
| `/admin/operations` | 대시보드+목록 | 알림 전달 실패/재시도 표기, 세션 차단 권한 잠금 |
| `/admin/sites` | 목록 | test 데이터 숨김 시에도 "실데이터 없음" 정직 표기 |
| `/admin/sites/[siteId]` | 상세 | 부분 입고 진행/실패, 배송 상태 알수없음=`확인 불가` |
| `/admin/qr-inventory` | 목록+위자드 | 샘플 미리보기 로딩/404, 자산 조치 상태별 잠금 |
| `/admin/accounts`·`/access` | 목록 | 권한 매트릭스는 정적이라 항상 채워짐. 초대/역할변경 권한 잠금 |
| `/admin/reports` | 목록/집계 | 미해결·응답률 알수없음=`—`, 내보내기 한도 |
| `/admin/profile` | 상세 | MFA 상태만(시크릿 미표시), 저장 오류 인라인 |
| `/admin/platform/*` | 목록/상세 | 과금 값 미확정=`—`, 등록은 슈퍼어드민 직접만 |

## 5. 가로지르는 규칙 (전부 §2 어휘 준수)

- 상태 전환에 **레이아웃이 튀지 않는다**(로딩→로드, 오류→복구).
- **`0` ≠ `—` ≠ `확인 불가`** 를 구분한다.
- **권한 없음은 구역을 떼지 않고 잠근다**(정보 위치가 사라지면 학습이 깨진다).
- **한도는 잔여를 말한다.** **오류는 복구 경로를 준다.**
- 차주 전화번호·시크릿은 어떤 상태에서도 그리지 않는다(`AGENTS.md`).
- 새 토큰은 필요 없다. 스켈레톤=`--tt-color-surface-muted`, 잠금=기존 `disabled`+muted,
  알림=`.admin-notice`, 빈=`.tt-empty-state`.

## 6. Codex에게

- **신규 구현 2개**: 스켈레톤(로딩) 패턴, 잠금/읽기전용(권한없음) 패턴 — 위 스펙대로 globals.css
  공통 블록에 추가하고 화면은 그 블록만 쓴다.
- 나머지는 기존 `.tt-empty-state`·`.admin-notice` 재사용.
- 콘솔 실화면 상태 눈대조는 스텝 D(스테이징 로그인) 이후 Claude가 수행.
